# 威胁模型与信任边界

## 场景和资产

业务要求接收小型文档包，例如 RAG 资料导入前的 ZIP。需要保护隔离区之外的现有文件、磁盘可用空间、输出命名空间、消费者看到的完整包状态及日志中的敏感名称。示例无真实标准、租户或客户材料。

攻击者能控制整个 ZIP，包括成员名、声明大小、压缩数据、CRC、属性及包内自报 JSON；不能控制代码/策略、操作系统、输入文件的本地祖先目录或私有工作区，也不具备并发替换目录的本地权限。

可信调用方决定 Limits、现有父目录和全新任务容器名。应用身份/租户策略不从包中推导。ZIP 校验后内容仍然不可信，不能把哈希或获准后缀当作可信标签。

## 边界与控制

| 边界 | 风险 | 本次控制 | 未覆盖 |
| --- | --- | --- | --- |
| 本地输入 → 内存快照 | 不稳定来源、超大输入 | 普通文件/link/reparse 检查、有界读取、不可变 bytes | 恶意本地替换、祖先链接竞争、完整硬内存隔离 |
| ZIP 元数据 → 路径/预算计划 | 路径越界、别名、链接、虚假大小 | 原名检查、保守 ASCII 命名空间、成员类型、声明预算 | 完整 ZIP 规范认证、解析器漏洞 |
| 解压流 → 暂存文件 | 声明与实际不符、过量写入、坏 CRC | 读取块限额、观测预算、先核对再写、EOF/大小/CRC | 解压器内部峰值分配、硬 CPU 限制 |
| 私有暂存 → payload | 半成品被消费、覆盖已有资料 | 独占新容器、全量验证后单目录重命名、只消费 payload | 强杀恢复、断电持久化、恶意本地并发、网络文件系统 |
| payload → 文本/模型/网页 | 活性内容、注入、权限继承错误 | 明确不自动执行/渲染/入库 | 格式内容审核、模型安全、授权检索、Windows ACL 设置 |

## 非目标

- 不制作或运行攻击程序，不连外部目标，不构造大体积递归归档，不启动 HTTP 服务。
- 不阻止获准文件内的任意字节；仅是隔离接收，不提供 CDR/杀毒/内容鉴别/版权合规结论。
- 不替代 worker 沙箱、用户/全局并发和配额、可信存储权限及维护中的解释器补丁。
- 文件模式 `0600/0700` 仅在支持其语义的平台有相应意义；Windows 应使用私有继承 ACL，不以 POSIX mode 数字声称完成隔离。

## 信任假设失效时

如果同一身份的恶意程序能改写工作区，它可在 lstat/mkdir/open/rename/cleanup 之间替换对象；这里的路径校验不构成内核安全边界。检查网络共享或 reparse 的静态属性也不能承诺没有竞态。此情境必须改用受限独立身份、受控挂载/ACL 及平台专用原子 API，并重新建模，不应继续宣称本版本适用。

成功后的文件也可能被其他可信业务进程修改；消费前可重新核对摘要，但这仍不是跨进程不可变存储或来源认证。
